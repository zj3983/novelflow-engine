# 爽文大纲推进引擎

## 规则

- 核心是情绪“过山车”和信息差：先让需求与压力形成落差，再让既有优势改变局面。它们适合需要蓄压、反击或兑现的阶段，不是每章必备模板。
- 信息差必须拆成可执行的四项：`主角与读者已知`写已由正典确认的事实，`对手错误认知`写对手具体信错了什么，`误判如何驱动冲突`写对手因此采取的行动与代价，`纠错与回报`写真相怎样让反击生效并改变结果。只写“双方有信息差”不算完成设计。
- 在题材与篇幅适合时，每约 5–15 章组织一轮宏观循环：`设局/需求 -> 打压/拉仇恨 -> 降维打击 -> 震惊与收割`。区间可随事件密度调整，不为凑章数拖延。
- `设局/需求` 写清主角要什么、为什么现在要、失败会付出什么；`打压/拉仇恨` 必须来自对手、组织、规则、危机或时限的可信动机，并让施压者承担资源、名誉、关系或行动成本，不能随机羞辱。
- `降维打击` 必须调用正典中已有的规则、信息、资源、身份或能力优势，可以是拆局、议价、举证、借势或局部胜出，不必总是一击杀敌。
- `震惊与收割` 先落具体收益，再选择少量有身份、有立场的人物作证；反应服务证据，不用整齐划一的惊叹代替结果。
- 每轮结尾说明本轮行动造成的新局面，让下一轮问题由当前结果生长，而不是凭空增加危机。

## 正例

主角与读者已知旧税契仍在有效期内，商会执事却误以为税契已经作废；他为保住独家供货权，押上三个月信誉额度封锁药材。这个误判驱使他公开拦货，主角才得以提交税契并让交割记录入档。执事看到记录后说：“我再拦货，先被查的就是商会。”主角拿到药材，也引来官仓核验税契来源的新问题。正例有效，因为错误认知直接造成冲突，纠错同时兑现收益和后续牵引。

## 反例

路人无缘无故当众羞辱主角，主角突然觉醒从未出现过的血脉，一招击败所有人，满街的人同时惊呼他深不可测。反例失败，因为仇恨随机、能力凭空出现、反应模板化，所谓胜利没有改变任何可追踪的资源、关系或处境。

## 结构示例

一轮大纲按完整因果链输出：`设局/需求`是主角急需通行资格，否则错过救人时限；`主角与读者已知`是旧令牌仍受城规保护；`对手错误认知`是守关者认定令牌已经失效；`误判如何驱动冲突`是守关者押上家族声望公开扣人；`降维打击`是主角依据城规申请复核；`纠错与回报`是资格生效、垄断证据曝光；`后续牵引`是守关者追查令牌来源。
