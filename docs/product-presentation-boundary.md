# 普通创作页面的产品边界

Issue #40 的硬约束：普通 Web 只表达作者的目标、当前可用状态和下一动作。工程数据不能通过折叠详情或高级模式重新进入页面。

## Build / Write

`creation_product.py` 在既有创作服务之上提供：

- `GET /file-projects/{id}/product/build`：准备进度、故事内容、自然语言问题、编辑表单和动作。
- `GET /file-projects/{id}/product/write`：章节目录、正文、候选、可读审查建议和人工确认动作。
- `POST /file-projects/{id}/product/actions`：提交不透明动作标识与不透明表单字段；返回提示或页面跳转。

`product_presentation.py` 负责工程状态、已知错误和内容字段的产品映射。未知错误使用保守文案，不回显异常、提示词或凭据。自然语言审查建议保留，原始报告不返回。

React 仅渲染产品 DTO，不获取或解析 Build Graph、artifact、revision、原始 diagnostics、能力矩阵或候选内部状态。共享项目容器在这两个路由不读取工程详情，离页中的旧请求也不能继续触发后续工程读取。机器接口继续保留，普通页面不消费它们。

## 写入与恢复

动作标识由当前权限依据计算，不携带可解码的工程记录，也不建立动作缓存。提交时重新读取状态、重算允许动作，再调用原处理函数。原来的输入验证、源漂移、版本、候选、Canon 硬阻断和人工确认仍由原处理函数最终裁决。进程重启后的旧标识需要刷新页面，不会误用旧动作。

项目锁内只读取与核对状态；模型执行在锁外。工作进度读取放在项目锁之前，避免与现有任务更新的锁顺序冲突。全局动作不逐一读取每章详情；编辑动作只解析匹配部分。

编辑表单修改已有内容字段，保留隐藏的契约与元数据；对已知缺少的修炼阶段名称、升级条件给出可填写字段。这里不提供任意结构替换的 JSON 编辑器。修复/重跑失败不覆盖已接受内容。

## 验收

- API 回归检查 DTO 无工程字段、只读无探测、保存复用原验证、过期动作被拒绝、确认只生效一次、硬阻断不被绕过、修复在锁外执行和失败恢复。
- 页面回归检查只请求产品接口、无工程 DOM、动作与表单、草稿保护、候选优先展示、人工确认、章节目录和复制。
- 专用真实 FastAPI + 浏览器联调使用隔离合成项目与注入模型：新建→规划→阻断候选→重新生成→人工确认→续写，以及标明来源的合成已完成首卷→跨卷→下一卷候选。
- 测试进程可使用工程 API 核对证据，但浏览器页面本身只消费产品接口。

本边界不是模型质量认证，不代表真实生成了 50 章，也不覆盖真实 provider 或依赖安全验收。其它历史页面的产品整理不在此次两个页面返工中扩张实施。
