# 全题材移动端网文排版设计

## 目标

所有小说默认采用适合手机阅读的段落排版，同时保持现代中文句子完整、对话自然。排版只控制正文呈现，不改变题材内容、人物语气或剧情结构。

## 唯一规则来源

通用写手提示词负责以下要求：

- 普通叙述段通常写一至两句完整的话，尽量不超过手机屏幕三行。
- 场景、动作、观察或话题发生变化时换段。
- 对话独立成段；换说话人就换段，同一人的完整发言不机械拆碎。
- 真正的转折、揭晓、打断或冲击可以使用单句短段。
- 换行不能代替主语、对象、原因、结果和自然语气，禁止电报式短句。

商业爽文技能不再重复排版规则，只负责施压、反击、兑现和爽点节奏。其他题材技能也不得覆盖通用排版。

## 题材例外

网游题材继续要求怪物属性、玩家面板和系统通告独立成段，并使用 Markdown 加粗的 `【内容】`。该要求保留在网游题材模块，不进入其他小说。

书信、聊天记录、诗歌、公告、清单等正文内特殊文本可以按自身格式展示，不强制拆成普通叙述段。

## 审稿同步

审稿不再用“每五段至少一个四至六句长段”判断质量，也不因全章短段直接判错。只检查：

- 是否出现长串电报式短句。
- 是否把多个说话人的台词挤在同一段。
- 是否把同一人的完整发言无意义拆碎。
- 是否滥用两三个字的冲击段。

审稿只报告问题，不自动改写正文。

## 实施边界

修改通用写手提示词、通用正文审查和商业爽文技能中的重复规则。现有正文不自动重排；新生成、重写或人工扩写的正文使用新规则。

## 验证

- 未启用任何技能的小说也能在写手提示词中看到通用排版规则。
- 启用商业爽文后，同一规则不会重复出现。
- 非网游小说不读取面板格式要求。
- 网游小说仍读取加粗面板格式要求。
- 审稿不再因缺少四至六句长段误判，但仍能发现电报式短句。
