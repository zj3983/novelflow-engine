# 网游长篇四阶段节奏模板设计

## 目标

为 `game_webnovel` 增加可复用的长篇节奏参考，使大纲生成能够同时推进游戏成长线、现实变化线和终极秘密线。该模板只属于网游题材，不进入通用网文模板，也不直接作为正文写手的整段提示词。

## 数据位置

在网游题材的 `genre_outline_template` 中增加 `arc.pacing_stages`。每个阶段包含：

- `id`：稳定阶段标识。
- `name`：阶段名称。
- `reference_range`：参考章数，不作为硬门槛。
- `stage_goal`：本阶段需要完成的总体变化。
- `game_line`：游戏内必须推进和兑现的内容。
- `reality_line`：现实中必须产生的结果。
- `advantage_progress`：主角核心优势的成长与使用方式。
- `mystery_progress`：终极秘密在本阶段揭露到什么程度。
- `required_payoffs`：阶段结束前必须兑现的结果。

## 四阶段内容

1. 新手期锋芒：获得并验证核心优势，完成首杀、纪录或首领争夺等有效胜利；形成第一轮竞争压力；取得第一笔可靠收益并解决初始现实危机。
2. 全服竞争与现实端倪：建立稳定队伍或势力，在大型玩法中形成影响力；核心优势发生一次明显成长；首次出现可信的能力反馈或现实异常。
3. 双线交织与世界异变：游戏反馈扩大到更多玩家和现实区域；现实组织介入；游戏身份、现实身份和社会责任开始互相影响；终极秘密从猜测进入可验证阶段。
4. 真相与终局：游戏规则失效、停服或两界融合；终极秘密完整揭晓；主角整合此前积累的人物、势力和能力，完成最终冲突并兑现结局方向。

以上章数参考分别为 `1-50`、`51-150`、`151-300`、`300+`，生成器必须根据 `planned_length` 和 `planned_arc_count` 等比例压缩或扩展。不得为了贴合章数而拖延升级、重复刷怪或提前泄露终极真相。

## 读取边界

- 开书和大纲生成读取完整四阶段模板，用于生成总纲与分卷。
- 章节规划只读取当前卷对应阶段和相邻阶段的交接要求。
- 正文写手只读取当前卷目标、本章任务和已经公开的秘密，不读取未公开终局答案。
- 审稿只检查阶段兑现、双线推进和秘密泄露，不要求每章同时出现游戏、现实与悬念。

## 兼容与回退

- 非网游题材不包含 `pacing_stages`。
- 自定义题材和旧模板缺少该字段时继续按现有逻辑生成。
- 旧网游项目在读取内置题材模板时自动获得节奏参考，不改写已经确认的历史章节。
- 项目自定义覆盖仍优先于全局内置模板。

## 验证

- 模板单元测试确认网游包含四阶段，其他题材不包含。
- 提示词上下文测试确认四阶段进入大纲阶段。
- 章节写作包测试确认不会把完整四阶段模板直接交给写手。
- 运行现有后端全量测试、TypeScript 检查和相关工作台浏览器测试。
