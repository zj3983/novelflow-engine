# 可选文风设计

## 目标

删除“通用白描”作为所有小说的默认文风。项目可以选择一种简单文风，也可以不选择；不选择时，写作流程只使用题材、大纲、人物和连续性信息，不额外注入文风要求。

## 文风选项

- 幽默
- 轻松
- 热血
- 冷峻
- 细腻

文风为单选且可清空。不增加强度、混合风格或自由文本配置。

## 运行规则

1. 新建和已有项目都允许不选择文风。
2. 未选择时，不使用“自然”“白描”或其他默认文风兜底。
3. 已选择时，写手只收到对应文风的一段简短表达要求。
4. 题材规则负责写什么，文风选项只负责怎么表达，两者不混在一起。
5. 文风审查只在项目选择文风后运行；未选择时跳过文风一致性判断。
6. 现有项目不自动迁移，不改动已经保存的正文。

## 界面

项目设置中提供一个可清空的文风单选控件。页面显示“未选择”以及五个文风选项，不出现“通用白描”。

## 代码范围

- 删除通用白描风格的默认注入和回退逻辑。
- 让写作任务书真正读取项目文风选项。
- 将文风选项转换为简短提示，不复制题材规则和通用写作禁令。
- 文风审查根据是否选择文风决定启用或跳过。
- 增加未选择、选择、清空和已有项目兼容测试。

## 验收标准

- 未选择文风的项目可以正常生成章节，写手提示词中没有通用白描兜底。
- 选择“幽默”等文风后，写手提示词只出现对应的简短文风要求。
- 清空文风后，下一次生成不再读取旧文风。
- 不同题材仍使用各自题材规则，文风选择不会改变世界设定或剧情账本。
