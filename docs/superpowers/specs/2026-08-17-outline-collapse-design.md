# 章节细纲折叠设计

## 目标

缩短章节细纲页面的纵向长度，让用户快速定位章节，同时不改变细纲数据、生成流程和保存逻辑。

## 交互

- 待写章节细纲按章节显示为独立折叠项。
- 折叠状态显示章节号、标题、本章目标和状态；展开后显示现有全部细纲字段。
- 页面提供“全部展开”和“全部折叠”命令。
- URL 中带有 `chapter` 参数时，对应章节默认展开，并在内容加载后滚动到该章节。
- 没有指定章节时，待写章节默认折叠。
- 已完成章节记录作为一个整体折叠区域，默认关闭。

## 边界

- 折叠状态仅属于当前页面，不写入项目文件。
- 不修改大纲接口、细纲结构和生成任务。
- 旧版待写章节与滚动细纲使用相同折叠交互。
- 空列表提示保持不变。

## 验证

- 指定章节会自动展开。
- 单章可以独立展开和折叠。
- 全部展开、全部折叠能控制所有待写章节。
- 已完成章节记录默认折叠且可展开。
- 类型检查与大纲页面相关测试通过。
