# 作品归档与回收站设计

## 目标

在“我的作品”中提供归档、移入回收站、恢复和彻底删除能力。归档用于收起暂时不写的作品；回收站用于防止误删；彻底删除必须经过更严格确认。

## 用户流程

作品首页分为三个视图：

- `创作中`：显示未归档、未删除的作品。
- `已归档`：显示归档作品，可恢复到创作中，也可移入回收站。
- `回收站`：显示已删除作品，可恢复到删除前状态，也可彻底删除。

每行作品右侧使用操作菜单：

- 创作中作品：`归档`、`移入回收站`。
- 已归档作品：`恢复创作`、`移入回收站`。
- 回收站作品：`恢复`、`彻底删除`。

归档和恢复直接执行并显示结果。移入回收站弹出普通确认。彻底删除要求输入完整小说名；输入不一致时按钮保持不可用。

## 状态模型

作品新增生命周期字段：

- `project_lifecycle`: `active | archived | trashed`，默认 `active`。
- `archived_at`: 归档时间，可空。
- `trashed_at`: 移入回收站时间，可空。
- `pre_trash_lifecycle`: `active | archived`，用于恢复到删除前视图。

恢复归档作品时，生命周期改为 `active`。从回收站恢复时，优先恢复到 `pre_trash_lifecycle`，没有旧值时恢复为 `active`。

项目原有 `status` 和 `pipeline_stage` 继续描述写作流程，不承担归档或删除含义。

## 存储策略

### 文件项目

归档只更新 `.webnovel/project.json` 和主设置中的生命周期元数据，不移动目录。

移入回收站时，将整个项目目录原子移动到导出根目录下的 `.trash/<project-folder>`。回收站目录内保存 `trash.json`，记录项目 ID、原目录、删除前生命周期和时间。恢复时检查原位置是否被占用；若占用则返回冲突，不自动改项目 ID。

彻底删除只允许删除 `.trash` 内经过校验的项目目录。后端必须解析并检查目标绝对路径仍位于配置的项目根目录或 `.trash` 根目录内，禁止由客户端提交任意文件路径。

### 数据库项目

归档和移入回收站更新项目生命周期字段。彻底删除复用现有项目删除逻辑，并删除该项目拥有的故事记录。

## 接口

统一向前端暴露以下操作：

- `GET /projects?lifecycle=active|archived|trashed`
- `POST /projects/{project_id}/archive`
- `POST /projects/{project_id}/restore`
- `POST /projects/{project_id}/trash`
- `DELETE /projects/{project_id}?confirm_title=...`

文件项目使用对应的 `/file-projects/{project_id}` 路由，前端 API 层根据项目 ID 和 `storage_source` 选择接口。列表接口返回生命周期和时间字段。

## 运行保护

归档、移入回收站和彻底删除前检查该作品是否存在 `queued` 或 `running` 的生成任务。存在活动任务时返回 `409 project_generation_active`，页面显示“作品正在生成，请完成或停止任务后再操作”。恢复操作不受该限制。

删除文件项目时同时清除进程内与该项目关联的任务索引，避免恢复后读取到旧活动任务。

## 错误处理

- 找不到项目：`404 project_not_found`。
- 恢复位置被占用：`409 project_restore_path_conflict`。
- 有活动生成任务：`409 project_generation_active`。
- 小说名确认不一致：`422 project_title_confirmation_mismatch`。
- 非法生命周期转换：`409 invalid_project_lifecycle_transition`。
- 文件移动或删除失败：保持原状态并返回明确错误，不留下列表状态与目录位置不一致的半成品。

## 前端

作品首页保留现有表格布局，顶部加入三个视图切换和各自数量。操作列使用图标菜单，避免横向堆叠按钮。确认框使用项目内模态框，不使用浏览器原生 `confirm`。

操作成功后只刷新作品列表。若当前记录的是刚删除作品的“上次打开作品”，清除本地存储；恢复不会自动改写上次打开作品。

## 测试

- 文件项目归档、恢复、移入回收站、恢复原状态、彻底删除和路径冲突。
- 数据库项目同等生命周期转换和级联删除。
- 活动生成任务阻止归档和删除。
- 列表按生命周期过滤且默认不显示归档、回收站作品。
- 前端三个视图、操作菜单、确认弹窗、错误提示和空状态。
- Windows 路径校验、目录移动和彻底删除限定在项目根目录内。
