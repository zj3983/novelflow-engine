# 网游越级战斗规则设计

## 目标

防止剧情仅靠“操作好”“计算准”让玩家随意越级杀怪，同时保留合理的挑战空间和有铺垫的特殊胜利。

## 核心规则

- 怪物等级高出玩家 1 至 2 级时，允许正常挑战，但正文需要体现更高的风险、资源消耗或战斗压力。
- 怪物等级高出玩家 3 级及以上时，默认不能由玩家正常单杀。
- 越 3 级及以上只有在剧情提前建立特殊理由时才允许，包括组队、任务道具、属性克制、特殊装备、地形机关、怪物残血或已建立的特殊能力。
- 走位、计算、谨慎和操作技巧只能提高战斗效率，不能单独构成越 3 级及以上单杀的理由。
- 等级差越大，特殊条件和胜利代价必须越充分；不能在击杀完成后才临时补充理由。

## 三层约束

### 世界规则

网游题材模块保存统一等级差规则，项目世界观可以增加更严格的限制，但不能放宽到无理由越级。怪物角色卡需要保留等级、战斗定位和关键机制，供推演与审稿读取。

### 剧情推演

推演战斗事件时比较玩家与怪物等级。等级差达到 3 级时，必须同时产出明确的特殊条件、条件来源和可见代价；缺少其中任意一项，就改为撤退、侦察、组队、获取道具或挑战同级怪物，不能继续安排击杀。

### 审稿检查

审稿从正文和本章计划提取双方等级。发现越 3 级及以上击杀时，检查特殊条件是否在战斗前出现。没有有效理由时列为硬问题，要求重写战斗结果或补全已经存在于大纲、角色卡、装备卡和世界规则中的依据，不允许审稿阶段发明新能力。

## 现有项目迁移

检查《苟在网游里成神》的总纲、卷纲、章节大纲和爽点规划：

- 将“精算打法越级杀怪”等笼统表述改为同级或高 1 至 2 级的高效战斗。
- 保留高出 3 级及以上的战斗时，补齐提前存在的组队、道具、克制、装备、地形或残血条件。
- 第一章和新手阶段不得安排 Lv.1 玩家正常单杀 Lv.5 精英怪。

## 验证

- 单元测试覆盖高 2 级正常挑战、高 3 级无理由击杀被拦截、高 3 级且具备有效条件时通过。
- 提示词测试确认写手能看到规则，但不重复注入冗长说明。
- 项目数据检查确认现有有效大纲不再包含无条件越 3 级击杀。
