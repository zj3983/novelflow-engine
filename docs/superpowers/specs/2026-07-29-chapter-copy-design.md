# 章节复制功能设计

## 目标

在小说章节阅读页提供一键复制功能，方便作者将当前章节直接粘贴到发布平台或其他编辑器。

## 交互

- 在正文标题区域的工具栏中增加“复制章节”按钮。
- 点击后复制当前章节的章节号、标题和正文。
- 文本格式为：`第 N 章 标题`，空一行后接正文。
- 复制成功后按钮短暂显示“已复制”，随后恢复。
- 复制失败时在章节工具栏附近显示明确错误信息，不影响生成和重新生成操作。

## 实现

- 仅修改章节页前端，不增加后端接口。
- 优先使用 `navigator.clipboard.writeText`。
- 为不支持 Clipboard API 或权限受限的环境提供隐藏文本域加 `document.execCommand("copy")` 的兼容回退。
- 复制状态独立于章节生成状态；切换章节时清除上一章的复制结果。

## 测试

- 验证复制文本包含正确章节号、标题、空行和完整正文。
- 验证复制成功状态会显示并自动恢复。
- 验证 Clipboard API 失败时启用兼容回退。
- 在桌面宽度和窄屏章节页确认工具栏不会遮挡标题或现有按钮。
