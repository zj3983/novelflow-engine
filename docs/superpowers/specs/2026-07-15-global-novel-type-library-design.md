# 全局小说类型库设计

## 目标

在工作台全局导航增加“小说类型”，集中查看和维护所有题材类型。新建小说、项目设置、推演和写作包都从同一类型库读取，避免前端选项、后端目录和题材规则各自维护。

## 页面

新增全局页面 `/novel-types`，与“作品”“配置”并列。

- 左侧为类型列表，显示名称、来源和简要说明。
- 右侧为当前类型详情与编辑表单。
- 可查看并编辑：名称、说明、关键词、核心承诺、账本字段、成长规则、经济规则、任务规则、势力规则、面板规则、章节结构、禁写项、质量检查。
- 提供“新增类型”“保存”“删除”命令。
- 内置类型可以编辑内容，但类型 ID 固定且不能删除。
- 自定义类型可以编辑和删除；删除前检查是否仍有小说使用。

## 数据边界

后端提供统一的类型库服务和 API，运行时返回“内置默认值 + 用户覆盖 + 自定义类型”的合并结果。

- 内置默认值仍由代码提供，保证首次启动可用。
- 用户修改和自定义类型持久化到全局数据目录，不改写源码文件。
- 项目只保存所选类型 ID，不复制整套类型规则。
- 写作和推演按类型 ID读取合并后的最新规则，因此编辑后无需逐本迁移。

## API

- `GET /novel-types`：读取合并后的全部类型。
- `POST /novel-types`：新增自定义类型。
- `PUT /novel-types/{id}`：编辑类型内容。
- `DELETE /novel-types/{id}`：删除未被项目使用的自定义类型。

所有写入执行字段校验、ID 唯一校验和空内容校验。内置类型拒绝修改 ID与删除。

## 兼容

- 现有八种类型 ID 保持不变。
- 旧项目继续按 `world_blueprint.genre_plugin_ids` 读取类型。
- 新建小说和项目设置改为请求类型 API；API 不可用时显示错误，不使用另一份硬编码可编辑列表。
- 题材插件加载、开书方向、大纲生成和写作包统一通过类型库解析类型内容。

## 验证

- 后端覆盖合并、增改删、内置保护、占用保护和持久化测试。
- 前端覆盖列表、详情、新增、编辑、删除和新建小说选项同步。
- 验证现有项目仍能读取原类型，修改类型后下一次写作包可读取新规则。
