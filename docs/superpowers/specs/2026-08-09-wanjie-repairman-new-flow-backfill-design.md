# 《万界维修工：从家电到仙器》新流程补全设计

## 目标

保留现有 147 章正文，依据正文和已确认章节产物，补齐新流程需要的故事核心、总纲、分卷大纲、世界观、角色卡、关系、伏笔和连续性状态。第 148 章起直接使用新流程。

## 事实优先级

1. 已确认章节正文与对应章节结构化产物。
2. 多章重复出现且没有冲突的稳定事实。
3. 当前项目中的明确设定。
4. 旧摘要、旧大纲和模型生成的补全内容。

低优先级资料与正文冲突时，以正文为准。补全不得创造已经发生但正文没有出现的事件。

## 处理范围

- 故事核心：一句话故事、核心卖点、主角长期目标、主要代价、终局问题。
- 总纲：开端、发展、中点、高潮、结局方向及可伸缩的长篇结构。
- 分卷大纲：整理现有 147 章所属阶段，并规划第 148 章之后的剧情方向。
- 世界观：现实层、修行层、万界层、维修能力边界、力量体系、势力、地点和重要物品。
- 角色：合并同一人物和错误实体，补齐身份、经历、欲望、弱点、关系、说话方式及当前状态。
- 连续性：回填章节摘要、时间线、伏笔、未解决矛盾、当前焦点与重要物品状态。

## 不处理

- 不重写、删除或重新排序现有 147 章正文。
- 不把旧摘要中的推测直接升级为世界规则。
- 不为填满字段而虚构人物、势力、功法或历史事件。
- 不保留与本书题材无关的网游专用字段和规则。

## 数据流

`147 章正文与章节 JSON -> 事实抽取与去重 -> 冲突检查 -> 核心/总纲/世界观/角色/关系/伏笔回填 -> 新流程上下文预览 -> 第 148 章生成前校验`

## 验收标准

- 147 章正文文件内容和数量不变。
- 页面可查看故事核心、总纲、世界观、人物关系和伏笔。
- 主角、主要配角、反派及重要物品没有重复实体。
- 当前章节、时间线、人物状态和未解伏笔能承接第 148 章。
- 第 148 章写作包只加载本书相关资料，不含网游规则。
- 新流程的导演、写手和事实审稿能够正常产出并通过结构校验。
